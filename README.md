# 🎯 Guess the Number Game

A fun and interactive number guessing game built using **JavaScript, DOM, HTML, and CSS**. The player tries to guess a randomly generated number between **1 and 100**, with helpful hints along the way!

## 🚀 Features
- Generates a **random number** between **1 and 100**.
- Provides hints based on the user's input:
  - **"Too low, select a higher number"** if the guess is too low.
  - **"Too high, select a lower number"** if the guess is too high.
  - **"You guessed correctly"** if the number is correct! 🎉
- Handles **invalid inputs** (e.g., letters, special characters) with a message:
  - **"Invalid Entry, please enter only a number."**
- Interactive and user-friendly design.

## 🛠️ Technologies Used
- **HTML** – Structure of the game.
- **CSS** – Styling for an intuitive UI.
- **JavaScript (DOM Manipulation)** – Game logic and interactivity.

## 🎮 How to Play?
1. Enter a number between **1 and 100**.
2. Click the **Guess** button.
3. Follow the hints to find the correct number.
4. Keep guessing until you win! 🎉
